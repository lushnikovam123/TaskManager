Менеджер задач (Task Manager)
Курсовая работа по дисциплине «Разработка программных модулей»
Автор
Лушников А. М., группа 2407r1
Руководитель
Банников В. С.
Описание
Приложение для управления личными задачами. Позволяет создавать, редактировать и удалять задачи, назначать им категории и приоритеты, а также отслеживать статус выполнения. Предусмотрены функции фильтрации, поиска и сохранения данных между сеансами работы.
Функциональные возможности
Создание, редактирование и удаление задач.
Назначение категории (Работа, Учёба, Личное) и приоритета (Низкий, Средний, Высокий).
Отметка о выполнении задачи.
Фильтрация списка задач по категории и приоритету.
Поиск задач по названию.
Отображение статистики выполненных задач.
Сохранение и загрузка данных (JSON / SQLite).
Используемые технологии
Язык программирования: C# 12
Платформа: .NET 8, WPF
Архитектура: MVVM (Model-View-ViewModel)
